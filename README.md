"GTA 6 Trailer 2 Craziest 13 Seconds" — a 13-second vertical clip of GTA 6 Trailer 2's wildest moments: the jetski chase, the seaplane takeoff, Lucia's gym fight, and a police-car fireball finale. It is cut to ride the Shorts feed, following the current #1's formula: one tight clip, a plain title, and a minimal description. The video is public at https://www.youtube.com/shorts/UDdoNYTQ6tc and VIDEO.json names it for the grader.

## Run it

```sh
node main.ts
```

`node main.ts` hands VIDEO.json to the grader: it validates the YouTube address inside and copies the file unchanged into the output directory.
